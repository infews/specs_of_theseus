# About

Specs of Theseus is written by **[Davis W. Frank](https://dwf.bigpencil.net/about_me/)**.

Davis has built software since the early 1990s: low-level graphics, computer games, smartphones, and web apps and SaaS, at large companies and startups alike. At [Pivotal Labs](https://labspractices.com/guides/tanzu-labs-engineer-faq/), Davis helped build Rails and mobile apps and co-wrote [Jasmine](https://jasmine.github.io/), the JavaScript testing framework.

Davis writes about software engineering and leadership at **[DWF's Journal](https://dwf.bigpencil.net/)**.

## Why This Method?

Specs of Theseus brings the Pivotal Labs flavor of software development to a team where agents write most, if not all, of the code. It pairs that with [Chad Fowler's Phoenix Architecture](https://aicoding.leaflet.pub/): durable specifications, disposable code. See the [overview](index.md) for how the pieces fit together.

## This Project

The method, its diagrams, and the `theseus` Claude Code plugin live at [github.com/infews/specs_of_theseus](https://github.com/infews/specs_of_theseus). Specs of Theseus is a work in progress. Issues and stories from trying it on real projects are welcome.
